# LightningCrowbar

一个兼容 Luminol/Folia 的 Paper 插件：使用带有特殊标记的铁镐作为撬棍。手持撬棍攻击生物时，会在目标位置召唤一道闪电，保留普通攻击伤害并叠加闪电伤害。

## 构建

需要 Java 25 和 Gradle 9 或更高版本：

```powershell
gradle build
```

构建产物位于 `build/libs/LightningCrowbar-1.0.0.jar`。将它放入 Luminol 服务端的 `plugins` 目录后启动服务器。

当前 Luminol 26.2 源码归档没有可下载的服务端发行包，因此本仓库的本地测试基线使用同 API 线的 Folia 26.2 build 7；Luminol 服务端可直接替换测试服 JAR。

## 游戏内测试

玩家可以直接执行：

```text
/lightningcrowbar give
```

获取钉砖：

```text
/lightningcrowbar givebrick
```

也可以指定在线玩家：

```text
/lightningcrowbar give <玩家名>
```

手持撬棍攻击任意生物即可触发闪电。撬棍也可以用两个铁锭和两根木棍按配方合成。

手持钉砖右键空气或方块进入固定状态，再次右键进入调整模式。固定状态会关闭重力，并阻止击退、活塞和外部传送造成的位置变化；只有按下移动键才会解除固定，转动视角不会解除。调整模式下按住 W/S/A/D 会以 `0.05` 格/刻微调，按住冲刺键会以 `0.5` 格/刻大调；按住空格持续上移，按住 Shift 持续下移。调整过程中外部位移仍会被拦截，完成后左键即可回到固定状态。

## 开发约定

钉砖调整移动系统作为后续开发的稳定基准。后续功能默认不修改其输入处理、步长、方向计算和异步传送流程；只有修复问题、测试需求或明确要求时才调整这部分逻辑。

## 躲猫猫

插件包含固定 10 分钟方案的躲猫猫模式。管理员执行 `/hns admin` 打开游戏内 GUI 控制台，可预设角色、随机分配、开始/停止游戏、跳转时间轴、强制结算以及发放道具。也可以使用 `/hns start`、`/hns stop`、`/hns randomize`、`/hns setrole <玩家> <hider|hunter>`、`/hns test <hider|hunter>`、`/hns kit` 和 `/hns status`。单人测试模式不会自动判定胜负，适合逐项验证时间轴和道具。

躲藏者体型时间轴为：开局 `1.0`，3 分钟 `1.5`，5 分钟 `2.0`，8 分钟 `3.0`。开局 30 秒拥有高速，随后进入低速状态。抓捕者常驻发光、速度和跳跃提升，且每 2 分钟提升一级力量。被击杀的躲藏者重生后成为能力较弱、没有雷达的普通抓捕者。

当前道具包括阿巴图坎片、固定棒、三级嘲讽哨、两刀剑、两箭弓、32 枚末影珍珠、手雷、区块雷达和追踪雷达。追踪雷达固定冷却 30 秒，命中躲藏者时立即重置。
