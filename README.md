# Luminol Hide and Seek

一个面向 Luminol/Folia 服务端的 10 分钟躲猫猫插件。插件提供完整的角色分配、体型时间轴、职业道具、淘汰转职、随机事件、胜负结算，以及可在游戏内直接调整规则的 GUI 管理控制台。

当前首个正式发行版为 **v1.0**，适配 Minecraft 26.2、Luminol 26.2 build 727 和 Java 25。

## 核心玩法

游戏分为躲藏者与抓捕者两个阵营。躲藏者需要利用小体型、短时加速、精确固定位置和嘲讽道具坚持 10 分钟；抓捕者依靠速度、跳跃、逐渐增强的力量、追击道具和雷达找出全部躲藏者。

- 对局固定为 10 分钟。
- 时间结束时仍有躲藏者存活，则躲藏者胜利。
- 所有躲藏者被淘汰，则抓捕者胜利。
- 躲藏者死亡并重生后，会转化为能力较弱的普通抓捕者。
- 对局结束时自动清除游戏道具、显示胜利标题并释放烟花。
- 行动栏持续显示剩余时间、下一个体型节点倒计时和存活躲藏者数量。

## 躲藏者

### 体型时间轴

默认体型经过换算后不会超过目标高度：

| 对局时间 | 目标高度 | 默认实际高度 | 默认缩放倍率 |
| --- | ---: | ---: | ---: |
| 0:00 | 1 格 | 约 0.97 格 | 0.54 |
| 3:00 | 1.5 格 | 约 1.48 格 | 0.82 |
| 5:00 | 2 格 | 约 1.98 格 | 1.10 |
| 8:00 | 3 格 | 约 2.97 格 | 1.65 |

每次体型变化时，躲藏者姿态会随阶段改变，并向所有玩家播放低速提示音和标题。管理控制台可以修改三个转换时间点和四个阶段的缩放倍率，同时会限制倍率不超过各阶段目标高度。

### 移动效果

- 开局默认获得 30 秒高速移动。
- 高速阶段结束后进入可配置的缓慢状态。
- 管理员可以调整缓慢触发时间和缓慢等级。
- 特殊道具和随机事件可以临时覆盖基础移动效果。

### 躲藏者道具

**阿巴土坎片**

使用唱片作为物品模型。直接右键空气或方块即可使用，使用后消耗 1 片，获得 3 秒巨额加速，随后进入 10 秒疲劳缓慢，并播放低音量、1.5 倍速的 `particle.soul_escape` 音效。通过嘲讽哨循环奖励最多补充到 3 片。

**固定棒**

右键进入固定状态，固定后不会被重力、击退、活塞或其他外部因素移动。玩家主动按下移动键时才会解除固定。

再次右键进入调整模式：

- `W/S`：沿玩家面向方向前后调整。
- `A/D`：左右调整。
- `空格/Shift`：持续向上或向下调整。
- 普通调整步长：每次 0.05 格。
- 按住冲刺键时：每次 0.5 格。
- 最大高度：进入固定状态时的位置上方 5 格。
- 左键结束调整并返回固定状态。

**三级嘲讽哨**

- 一级：恶魂音效。
- 二级：末影人音效。
- 三级：末影龙音效。
- 每个等级独立冷却：一级 15 秒、二级 25 秒、三级 35 秒，可以重复使用。管理台可以在声音模式和特效模式之间切换；特效模式分别对应爱心粒子、头顶爱心粒子和蓝色高亮。三种等级各使用一次后，玩家最多补充到 3 片阿巴土坎片。

## 抓捕者

初始抓捕者常驻速度、跳跃提升和全局高亮，并且每经过两分钟提高一级力量，最高提升至五个效果等级。由躲藏者转化而来的普通抓捕者速度和跳跃效果更弱，不会获得额外力量，也没有雷达。

### 抓捕者道具

- **下界合金剑**：两次有效命中淘汰躲藏者。
- **猎人弓**：两支专用箭命中后淘汰躲藏者。
- **末影珍珠**：每套 32 枚，用于追击和位移。
- **手雷**：物品模型为雪球，直接右键空气或方块会从玩家视线前方发射带射手信息的雪球实体。同一玩家上一枚手雷落地前不能再次投掷；落地后进入 5 秒冷却并显示为灰色染料，冷却结束恢复为雪球。落地显示 3 格范围粒子环，范围内的躲藏者持续发出潜影贝声音 5 秒并播放命中音效。
- **小摔炮**：物品模型为鸡蛋，直接右键空气或方块会发射带射手信息的鸡蛋实体并禁止孵化。同一玩家上一枚摔炮落地前不能再次投掷；鸡蛋落地后开始计算冷却：未命中躲藏者时冷却 5 秒，命中时立即恢复可用；冷却期间显示为灰色染料，结束后恢复为鸡蛋。落地显示 2 格范围粒子环并播放命中音效。落点 2 格范围内按目标分别累计命中：第一次施加缓慢 V 5 秒，第二次刷新缓慢并显示大量水滴粒子 5 秒，第三次造成 10 点伤害并播放蠹虫受伤音效，随后该目标的计数重置。
- **范围雷达**：显示指定范围内的躲藏者数量，使用后进入 3 秒独立冷却；冷却期间显示为灰色染料，不影响追踪雷达冷却。
- **追踪雷达**：直接右键即可向同世界最近的躲藏者发射极低速潜影贝子弹，不受范围雷达设置影响。使用后冷却期间显示为灰色染料，子弹可以穿过实体和方块，飞行 50 秒后自动清除；命中躲藏者后播放末影人叫声并暴露目标。

追踪雷达默认冷却 30 秒。初始抓捕者成功淘汰躲藏者时会立即重置冷却。

## 雷达模式

管理控制台可以循环切换雷达查询范围：

- **区块模式**：范围雷达统计当前区块；追踪雷达始终搜索同世界最近躲藏者，不受此模式影响。
- **边长 1～10 格正方形模式**：以使用者所在方块为中心，在 X/Z 平面查询对应边长的正方形区域。偶数边长向正方向多覆盖一个方块，以保持总方块数准确。

只有范围雷达计数遵循当前模式，追踪雷达始终为无范围限制的同世界搜索。

## 随机事件

随机事件默认关闭，可以在管理控制台中启用。管理员可以控制总开关、单个事件开关、触发模式和事件间隔。

内置事件：

- 全体躲藏者暴露 5 秒。
- 躲藏者获得额外缓慢 10 秒。
- 抓捕者获得额外速度 10 秒。
- 躲藏者获得短暂加速 5 秒。

触发模式：

- **随机模式**：在配置间隔附近随机选择触发时间。
- **定时模式**：每达到指定间隔时触发一次已启用事件。

## 游戏管理控制台

管理员在游戏中执行：

```text
/hns admin
```

GUI 控制台采用主菜单和二级菜单：

- **游戏控制**：开始/停止、状态、角色随机分配、单人测试、按当前配置跳到体型阶段 1/2/3，以及胜负结算。
- **玩家与角色**：点击在线玩家头像预设躲藏者或抓捕者。
- **规则与体型**：编辑三个体型转换时间点、四阶段倍率，以及躲藏者减速时间和等级。
- **躲藏者道具**、**抓捕者道具**：逐项切换开局是否发放。设置会持久化到 `config.yml`；普通抓捕者仍不会获得雷达。
- **雷达与随机事件**：调整范围雷达区块/边长 1～10 格范围，配置随机事件总开关、事件开关、随机/定时模式和间隔。追踪雷达不受范围选择影响。
- **嘲讽哨设置**：切换嘲讽哨声音/特效模式并查看各级冷却；嘲讽哨直接右键即可使用，冷却期间显示为灰色染料，结束后自动恢复。

正式局玩家名单由佩戴蓝色染色并带有插件特殊标签的“躲猫猫参赛帽”的在线玩家组成。管理员可使用 `/hns givehat [玩家]` 发放参赛帽；未佩戴参赛帽的玩家不会被纳入正式局。

体型节点按钮左键增加 30 秒，右键减少 30 秒。系统会自动保证三个时间点保持递增且位于 10 分钟对局范围内。所有规则设置会保存到插件的 `config.yml`。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/hns admin` | 打开游戏管理控制台 |
| `/hns start` | 开始正式对局 |
| `/hns stop` | 停止当前对局 |
| `/hns randomize` | 随机预设在线玩家角色 |
| `/hns setrole <玩家> <hider\|hunter>` | 设置玩家下一局角色 |
| `/hns givehat [玩家]` | 发放躲猫猫参赛帽，佩戴后加入正式局名单 |
| `/hns test <hider\|hunter>` | 开始单人功能测试 |
| `/hns kit` | 补发当前角色道具 |
| `/hns status` | 查看游戏状态 |

管理功能默认需要服务器管理员权限 `lightningcrowbar.hns`。

## 安装与构建

运行环境：

- Minecraft 26.2
- Luminol `26.2 build 727` 或同 API 线的 Folia
- Java 25
- Gradle 9 或更高版本

构建：

```powershell
gradle clean build
```

构建产物位于：

```text
build/libs/LightningCrowbar-1.0.jar
```

将 JAR 放入服务器的 `plugins` 目录，完整重启服务器即可。插件声明 `folia-supported: true`，调度逻辑使用 Folia/Luminol 的全局、实体与玩家调度器。

## 默认配置

首次启动后会生成 `plugins/LightningCrowbar/config.yml`。主要配置包括：

```yaml
hns:
  scales:
    0: 0.54
    1: 0.82
    2: 1.10
    3: 1.65
  scale-thresholds:
    1: 180
    2: 300
    3: 480
  hider-slow:
    trigger-seconds: 30
    amplifier: 5
  radar:
    mode: CHUNK
  whistle:
    mode: SOUND
  items:
    hider:
      abatukan: true
      nail-brick: true
      whistle-1: true
      whistle-2: true
      whistle-3: true
    hunter:
      sword: true
      bow: true
      arrow: true
      pearl: true
      grenade: true
      small-firecracker: true
      radar: true
      tracking-radar: true
  random-events:
    enabled: false
    mode: RANDOM
    interval-seconds: 120
```

建议优先通过游戏内管理控制台调整规则，以避免填写无效的时间顺序或超出体型上限。
