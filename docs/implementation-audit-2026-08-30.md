## 尚未完全符合要求的项目

1. 当前 `Attribute.SCALE` 使用 `1.0/1.5/2.0/3.0` 倍率，不是实际碰撞箱的 1、1.5、2、3 格高度。默认玩家约 1.8 格高，3.0 倍约为 5.4 格。
2. 特殊剑和弓按两次命中计算，但猎人使用普通武器或空手时，原版伤害没有被阻止，可以绕过两刀或两箭规则。
3. 最后一名躲藏者死亡后，要等其重生并完成角色转换才会判定猎人胜利；停留在死亡界面会延迟结算。
4. 普通猎人的力量效果放大等级为 `0`，在 Minecraft API 中实际代表力量 I，不符合“没有额外伤害加成”。
5. 追踪雷达命中后使用潜影贝发射声，而不是指定的末影人叫声。
6. GUI 可以控制角色、时间、开始、停止、道具和胜负，但不能编辑体型、时间节点、药水等级、道具数量、命中次数、雷达冷却和范围等全部规则数据。
7. GUI 的“发放当前角色道具”只发给点击按钮的管理员本人，不会给指定玩家或所有玩家补发。
8. 追踪雷达击杀重置冷却依赖 `Player#getKiller()`；由于两次命中通过取消伤害事件后直接设置生命值为零实现，需要多人实测确认击杀者能否被稳定识别。

## 当前操作流程

1. 正式游戏至少需要两名玩家，并确保背包有足够空位。
2. 管理员使用 `/hns admin` 打开控制台。
3. 点击玩家头像设置抓捕者或躲藏者，或使用随机分配。
4. 点击“开始 10 分钟游戏”，系统自动分配效果并发放角色道具。
5. 管理员可通过 GUI 查看状态、前后调整 30 秒、跳转到 3/5/8 分钟或强制结算。
6. 躲藏者坚持到 10 分钟则获胜；所有躲藏者转化后抓捕者获胜。
7. 单人测试使用 `/hns test hider` 或 `/hns test hunter`，结束时使用 `/hns stop`。

## 道具操作

- 阿巴图坎片：右键，极速 3 秒，然后缓慢 10 秒。
- 固定棒：第一次右键固定，第二次右键进入调整；W/S/A/D 水平移动，空格上移，Shift 下移；普通移动每刻 0.05 格，按住冲刺每刻 0.5 格；左键完成调整；固定状态按移动键解除。
- 嘲讽哨：右键消耗，依次播放恶魂、末影人和末影龙声音。
- 手雷：右键投掷，落点三格范围内的躲藏者暴露 5 秒。
- 区块雷达：右键显示当前区块的躲藏者数量。
- 追踪雷达：右键朝同世界最近躲藏者方向发射潜影贝子弹，基础冷却 30 秒。
